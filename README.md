# 🎞️ CSS Image Slider

A simple and responsive **Image Slider** created using **HTML and CSS**.
This project demonstrates how to create a clean slider layout with smooth transitions and a responsive design.

## ✨ Features

* 📸 Image Slider
* 🎨 Clean and modern UI
* 📱 Responsive Design
* ⚡ Smooth CSS Transitions
* 💻 Built with HTML & CSS
* 🌐 Easy to customize

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
css-image-slider/
│
├── index.html
├── style.css
├── images/
│   └── image files
└── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

```bash
git clone YOUR_REPOSITORY_URL
```
